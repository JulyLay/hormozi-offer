## 🚀 Як встановити

Відкрий Claude Code, новий чат, встав промт:

```
Встанови мені скіл з репозиторію https://github.com/JulyLay/hormozi-offer.git так, щоб він був доступний у будь-якому чаті назавжди:
1. Зклонуй репозиторій у ~/.claude/skills/hormozi-offer (якщо папки ~/.claude/skills немає — створи).
2. Видали з неї папку .git.
3. Перевір, що є файл ~/.claude/skills/hormozi-offer/SKILL.md.
4. Зроби все сам і коротко підтверди, що скіл встановлено.
```

Або командою в терміналі:

```bash
git clone https://github.com/JulyLay/hormozi-offer.git ~/.claude/skills/hormozi-offer && rm -rf ~/.claude/skills/hormozi-offer/.git
```

Далі просто опиши задачу в чаті або виклич `/hormozi-offer`.
