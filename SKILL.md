# Hormozi Offer — Створення невідпорних оферів

Скіл для створення оферів за методологією книги **$100M Offers** Алекса Хормозі. Мета — створити «Офер Великого Шлему» (Grand Slam Offer), який виглядає настільки цінним, що клієнт почувається дурником, якщо відмовиться.

Повна методологія: [methodology.md](methodology.md)

## Джерела даних (пріоритет)

Перед створенням офера ЗАВЖДИ шукай наявні дані:
1. **Файли проєкту** — опис продукту, ЦА, тарифи, конкуренти
2. **ДНК Клієнта** — якщо є готовий аналіз болів і бажань аудиторії (ідеальна основа для офера)
3. **Запитання користувачу** — якщо даних недостатньо

## Базові принципи (з чого все починається)

- **Не знижуй ціну — підвищуй цінність.** Зниження ціни — це гонка на дно. Замість цього виходь із «комодитизації» через диференціацію й унікальну упаковку.
- **Голодна юрба важливіша за хот-дог.** Спершу обери правильний ринок за 4 факторами: сильний біль, купівельна спроможність, легкість таргетингу, потенціал зростання.
- **Багатство в нішах.** Чим вужча ніша, тим вищу ціну можна ставити.
- **Заплатять стільки, скільки це коштує.** Висока маржа → ресурси на якість → кращий результат → ще вища цінність («порядний цикл ціни»).

## Рівняння цінності (серце методології)

```
              (Результат мрії) × (Сприймана ймовірність успіху)
Цінність =  ─────────────────────────────────────────────────────
                (Час до результату) × (Зусилля і жертви)
```

**Завдання:** підвищувати верхні елементи (чітко показувати результат, гарантувати успіх) і знижувати нижні (робити швидше, простіше, приємніше). Люди платять за впевненість.

## Алгоритм створення офера (5 кроків)

### Крок 1: Визнач результат мрії клієнта
Що насправді хоче клієнт? Не процес («самокат»), а пункт призначення. Бери з ДНК Клієнта, якщо є.

### Крок 2: Склади список усіх проблем
Дивергентне мислення — випиши ВСІ перешкоди й заперечення, що стоять між клієнтом і результатом. Чим більше проблем знайдеш, тим більше рішень зможеш запропонувати.

### Крок 3: Перетвори кожну проблему на рішення
Для кожної проблеми — конкретне рішення з зрозумілою, привабливою назвою.

### Крок 4: «Скоротити і вкласти»
Обери спосіб надати ці рішення в найзручнішому для бізнесу форматі (час/ресурси розумні). Спершу вручну → потім оптимізуй і пакуй у групову/автоматизовану форму.

### Крок 5: Сформуй підсумковий пакет
Комплект, що вирішує всі проблеми клієнта — і при цьому залишає високу маржу. Коли закриті всі проблемні вузли, у клієнта немає причин сказати «ні».

## Підсилювачі офера

Базовий цінний офер можна зробити невідпорним за допомогою (деталі в [methodology.md](methodology.md)):

1. **Дефіцит** — обмежена кількість місць/одиниць («беремо тільки 25 клієнтів»). Має бути чесним.
2. **Терміновість** — обмеження в часі (дедлайн запуску, акції). Без дедлайну люди тягнуть вічно.
3. **Бонуси** — кожен бонус закриває окрему перешкоду; яскрава назва + зрозуміла грошова цінність. Краще додати бонус, ніж знижку.
4. **Гарантії** — знімають головне заперечення «а раптом не спрацює». Безумовна / умовна / анти-гарантія / мається на увазі (pay-per-result). Сильна гарантія може підняти конверсію в 2-4 рази.
5. **Назва (нейминг)** за формулою **M-A-G-I-C**:
   - **M**agnet — магнітна причина (чому ця акція/програма)
   - **A**vatar — для кого це
   - **G**oal — яке бажане досягнення
   - **I**nterval — за який час результат
   - **C**ontainer — форма (програма, інтенсив, челендж)

## Алгоритм роботи зі скілом

1. Збери дані про продукт, ЦА, результат мрії (з файлів / ДНК Клієнта / запитань)
2. Прожени 5-кроковий процес створення офера
3. Додай підсилювачі: дефіцит, терміновість, бонуси, гарантію, яскраву назву
4. Збери все в готовий офер (структуру продаючої сторінки/скрипта)
5. Запропонуй протестувати назви та елементи, доопрацювати під зворотний зв'язок

## Правила поведінки

- **Веди діалогом** — по кроках, з паузами, не видавай усе одразу
- **НІКОЛИ не вигадуй факти** — цифри, гарантії, кейси бери з даних користувача. Не знаєш — запитай
- **Спирайся на ДНК Клієнта** — список проблем і результат мрії беруться з реальних болів аудиторії
- **Мова** — українська (якщо користувач не спілкується іншою)
- **Фокус на дії** — мета не ідеальний офер на папері, а швидкий запуск і шліфування по реакції ринку
